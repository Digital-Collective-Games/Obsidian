# BUG-0007 — Assign popup: ASSIGN button off-screen, task list doesn't scroll, opens at desktop top-left

- **Task:** Task-0016
- **Opened:** 2026-06-02 (found by the human playing with the LIVE WORKTREES tab)
- **Severity:** blocking the Assign flow on the human surface — the operator cannot see/click ASSIGN
- **Status:** FIXED (frontend); needs the dashboard re-roll to go live

## Symptom (human-facing, screenshot-confirmed)

Opening the Assign Task popup on an idle worktree: the task list (several tasks with long,
wrapped titles) fills the fixed-size popup and **pushes the ASSIGN / CANCEL buttons below the
visible area** — the human can't reach ASSIGN, so the whole Assign flow is unusable. The task
list does **not** scroll, and the popup opens at the **desktop top-left** instead of centered
on the dashboard overlay.

## Root cause

`open_assign_popup` ([app/codex_dashboard/ui.py](../../app/codex_dashboard/ui.py#L1564)):
- Fixed `popup.geometry("420x420")` with **no parent-centered position** → opens at the Tk
  default (desktop corner).
- The task-list frame was packed `fill="both", expand=True` **above** the button row, with
  the buttons packed afterward — so a long list grows and shoves the later-packed buttons off
  the bottom.
- No scroll on the list → tasks beyond the popup height (and the buttons) are unreachable.

## Fix

- **Buttons pinned to the bottom, always visible:** the ASSIGN/CANCEL `button_row` is packed
  FIRST with `side="bottom"`, so the task list can never push it off-screen no matter how many
  tasks it holds.
- **Scrollable task list:** the radio-button list lives in a `Canvas` + `ttk.Scrollbar` (with
  mousewheel + drag), packed `side="top", fill="both", expand=True` so it fills the space
  between the header and the pinned buttons and scrolls when it overflows.
- **Centered on the overlay:** the popup geometry is computed from the overlay's
  `winfo_rootx/rooty/width/height` (centered), not the desktop top-left. Popup enlarged to
  `460x520`.

## Verification

- `python -m py_compile app/codex_dashboard/ui.py` clean; `python -m unittest` green (62).
- LIVE (after the dashboard re-roll): open the Assign popup with enough tasks to overflow →
  ASSIGN/CANCEL visible, list scrolls to reach lower tasks, popup centered on the overlay
  (REG-019).
